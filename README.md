# 给小雨宝宝的雪地圣诞树

线上礼物：https://chrisocling.github.io/starlit-christmas/

源码：https://github.com/chrisocling/starlit-christmas

全屏只有树、白色雪地、飘雪和礼物。树体、积雪、灯带和树顶星星完全由光点组成，没有实体树层、树干或装饰球网格。桌面版树身约 13.2 万粒子，手机约 6.4 万；光点更大、更明亮，绿色更浓，有沿树身流动的光波和环绕光迹。空间里环绕着粒子雪晶、星星和圣诞挂饰（桌面 44 个、手机 28 个，围绕树一圈漂浮）。礼物保留完整 360° 环绕，每次打开随机生成距离、大小、朝向、包装与形状，并检查间距；桌面 24 份、手机 18 份。照片仍可挂在枝头，并通过手势展开。

## 打开与操作

- 点树顶星星，打开照片、摄像头、音乐和全屏设置；关闭后回到纯场景。
- 拖动旋转，滚轮或双指缩放；右键或长按也能打开设置。
- 双击、空格、右方向键放出下一张照片；左方向键回看上一张。
- 点击照片或按 Esc 收起照片，照片也会在 12 秒后飞回树里。
- P 批量选照片，G 开关摄像头，M 开关音乐。
- 主画面没有标题、导航、底栏、引导文字或操作面板。

## 手势与照片

开启摄像头后，张开手、握拳或拇指食指捏合，任意一种稳定约 0.3 秒都会放出一张照片。持续保持同一个手势只触发一次；放下手约半秒，再做一次相同手势，可以换下一张。两次出片至少间隔 1.2 秒，减少误触和闪烁。

照片从枝头飞到镜头前，以真实比例展示，不裁剪大图，随后回到树里。相册随机遍历，一轮看完前不会重复；树上最多同时挂出 28 张缩略照片，整本相册都可通过手势翻到。

### 自己导入

点树顶星星，选择「批量放入照片」，也可以将照片直接拖进窗口。最多 300 张，自动压缩长边至 1600 像素并生成小缩略图，去除原始文件中的附加元数据。支持 JPEG、PNG、WebP、AVIF；HEIC/HEIF 是否可读取取决于浏览器。不支持的图片会跳过并提示。

自己导入的照片保存在该浏览器的 IndexedDB，刷新仍然保留；不会上传，也不会因为发出网页链接而同步给另一台设备。浏览器不允许保存或空间不足时，会明确提示刷新后需重新导入。相同图片再次导入会自动去重。

### 给链接里的访客预先放好照片

目前没有预放个人照片，等待本人提供。要让小雨打开链接就能看到照片，将选好的图片放入 `public/photos/`，并编辑 `public/photos/manifest.json`：

```json
{
  "photos": [
    {
      "id": "memory-001",
      "src": "memory-001.jpg",
      "thumb": "memory-001-small.jpg",
      "caption": "我们的回忆"
    }
  ]
}
```

`src` 和 `thumb` 均相对 `public/photos/`；`thumb` 可以省略。预放在这里的照片会随公开网页发布，所有打开链接的人均可看到。更换照片后重新构建和发布即可。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

通过终端显示的 localhost 地址访问，不要直接双击 HTML。

```sh
npm test
npm run build
npm run preview
```

`main` 保存源码，GitHub Pages 从 `gh-pages` 根目录发布构建后的 `dist/`。发布时完整更新该分支，保留 `models/`、`vendor/wasm/` 和 `photos/`。相对资源路径同时支持本地域名根目录和 GitHub Pages 项目路径。

## 实现与隐私

Three.js、GPU 粒子着色器、Bloom、环境反射、柔和投影、圆角礼盒与缎带；Anime.js 负责照片飞出和回收；MediaPipe 手部模型在本机处理摄像头画面。模型、WASM 与图片都由同一站点提供，无运行时第三方 CDN 依赖。音乐由 Web Audio 合成，不需要音频文件或麦克风。

摄像头需要 HTTPS 或 localhost，以及浏览器授权。关闭摄像头、离开页面会停止媒体轨道；页面不可见时停止绘制和检测。批量导入时暂时停止背景绘制与识别，把性能留给照片处理。系统设置「减少动态效果」时关闭雪花运动并缩短动画。

测试覆盖三种手势、旋转缩放不变性、保持与重新做手势、防抖、300 张相册的遍历与不重复，以及浏览器端导入、去重、保存、照片展开和摄像头模型流程。
